# gabrielsvieira01.github.io

Site pessoal hospedado no GitHub Pages, com algumas ferramentas feitas pra apoiar a faculdade de Medicina.

## O que tem aqui

- **Agenda interativa do 8º período** (`agenda/`): calendário semanal com filtros por categoria e grupo, link compartilhável, modo foto e modo de incorporação (embed).
- **Simulados de OSCE do 7º período** (`osce7p/`): sem relação com a agenda.
- **Pomodoro Mundo Vivo** (`pomodoro-vivo/`):  pomodoro com cenas ilustradas, construída do zero com arquitetura modular (engine/câmera/componentes/temas separados), crescimento determinístico e fauna com viés real por organismo.
- **Registro de peso** (`registro-peso/`): página que serve de interface para uma planilha do Google, usada como banco de dados via Apps Script. Lança o peso do dia e desenha a evolução com média móvel de 7 dias.
- **Índice de navegação** (`index.html`): lista os arquivos `.html` do repositório.
